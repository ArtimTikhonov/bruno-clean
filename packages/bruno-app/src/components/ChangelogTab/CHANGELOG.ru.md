## Bruno 2.1.0

Неофициальный форк ArtimTikhonov на основе открытых исходников Bruno под лицензией MIT.

- Русский интерфейс по умолчанию; English можно выбрать в разделе Настройки → Основные → Язык.
- Отдельная настройка английских IT-терминов: Headers, Body, Query Params, Token, Proxy, Cache и другие. Для изменения языка и терминологии нужен перезапуск.
- Удалены ИИ-чат, генерация, ИИ-автодополнение и SDK провайдеров.
- Убраны реклама Golden Edition и удалённая лента объявлений Bruno.
- Приложение и исполняемые файлы называются Bruno / bruno; внутренний идентификатор сохранён для существующих настроек.
- Версии приложения, установщиков и тегов согласованы: v2.1.0.

HTTP-методы, имена переменных, URL, код и содержимое запросов и ответов не переводятся.
Форк не разблокирует закрытые коммерческие модули и не обещает полного набора возможностей платных редакций.
