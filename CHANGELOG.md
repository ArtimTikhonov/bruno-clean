# История изменений

Изменения неофициального форка ArtimTikhonov/bruno-clean.
Номера форка не обозначают соответствующую версию официального Bruno.
Правила — в [versioning.md](docs/fork/versioning.md).

## [Unreleased]

Пока нет изменений после 2.1.0.

## [2.1.0] - 2026-11-13

Первый релиз форка с согласованной семантической версией.

### Добавлено

- Русский интерфейс по умолчанию: меню, настройки, редактор запросов, окружения и сообщения.
- Выбор English с сохранением настройки после перезапуска.
- Настройка английских IT-терминов: Headers, Body, Query Params, Token, Proxy, Cache и другие.
- Проверки переводов, подстановок, русских форм множественного числа и сохранности пользовательских значений.
- Проверка версий пакетов, lockfile, Git-тега и записи в истории изменений.
- Инструкции для пользователей, разработчиков и выпускающих релизы; шаблоны обращений для форка.

### Изменено

- Отображаемое имя приложения и установщика — Bruno; исполняемые файлы — `bruno.exe` и `bruno`.
- Внутренний идентификатор сохранён, чтобы переименование не меняло расположение настроек.
- Публичные релизы выпускаются по тегам `vX.Y.Z` после проверок Windows x64 и Linux x64.
- Версии приложения и имена установочных файлов согласованы; прежние `clean-build-N` остаются в истории.

### Удалено

- ИИ-чат, генерация скриптов и документации, ИИ-автодополнение редактора.
- Обработчики ИИ-запросов, хранилище ключей в коде и SDK ИИ-провайдеров.
- Продвижение Golden Edition, кнопка объявлений и загрузка удалённой ленты объявлений Bruno.

### Исправлено

- Локализация выполняется до переноса JSX компилятором React Compiler.
- Удалена оставшаяся зависимость панели запросов от состояния ИИ-чата.
- Изолированы профили проверок запуска; выбирается Windows x64 установщик.
- Маскирование чувствительных значений в диагностике mock-сервера сохранено независимо от удалённого ИИ.

### Проверка выпуска

- Windows x64: установка NSIS и запуск установленного приложения.
- Linux x64: упаковка AppImage и запуск приложения.
- Обе платформы: русский интерфейс, сохранение английских IT-терминов после перезапуска, переключение на English.
- Контрольные суммы SHA-256 для установочных файлов.

## Предварительные сборки

`clean-build-2`, `clean-build-4`, `clean-build-7`, `clean-build-10` — исторические сборки до введения
согласованного версионирования. Они могли содержать разные изменения при одинаковой версии пакетов `2.0.0`.
Существующие теги и файлы не переименовываются и не заменяются.
