# Выпуск сборок этого форка

Актуальная инструкция: [Версии и выпуск релизов](docs/fork/versioning.md).

Windows x64 и Linux x64 публикуются в GitHub Releases по тегам `vX.Y.Z`
после проверок обеих платформ. Публикация upstream npm-пакетов, Homebrew,
Winget и других каналов оригинального Bruno этим форком не выполняется.
